# 🎯 Reconocimiento Facial con DeepFace + SVM  
## Usando el dataset LFW DeepFunneled (Kaggle)

Este proyecto implementa un sistema completo de **reconocimiento facial** utilizando:

- 🧠 **DeepFace (FaceNet512)** para extracción de embeddings faciales  
- 🎛 **SVM** (Support Vector Machine) para clasificación supervisada  
- 🖼 **Tkinter** como interfaz gráfica  
- 📁 Dataset **LFW DeepFunneled** (descargado de Kaggle)  

Es un sistema moderno y robusto de identificación de personas, similar a sistemas reales de reconocimiento facial.
